# homebrew-tap

Homebrew formulas for Pavel Akhrameev's projects.

## Formulas

| Formula | Install | Project |
|---|---|---|
| simslim | `brew install akhrameev/tap/simslim` | [Akhrameev/simslim](https://github.com/Akhrameev/simslim) |

`simslim` here is the Swift port, not upstream's Go build. It conflicts with `mobai-app/tap/simslim`
because both install a `simslim` binary.
